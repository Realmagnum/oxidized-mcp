# oxidized-mcp

MCP-сервер для семантического поиска по конфигурациям сетевых устройств, хранящихся в Git-репозитории Oxidized.

Предоставляет ИИ-агентам (OpenCode, Claude и др.) набор инструментов для быстрого и точного поиска настроек в конфигах коммутаторов. Ключевое отличие от «сырого grep» — понимание синтаксиса и структуры конфигов конкретных вендоров через систему плагинов.

## Архитектура

```
┌─────────────────────────────────────────────┐
│              MCP Server (core)               │
│  • MCP-протокол (stdio)                     │
│  • Роутинг запросов к плагинам              │
│  • Кэш прочитанных конфигов (TTL)           │
│  • Определение вендора по файлу/пути        │
│  • Отметка времени последнего коммита       │
├─────────────────────────────────────────────┤
│           Git Reader (модуль)               │
│  • чтение файлов из рабочего дерева         │
│  • git grep для быстрого поиска             │
│  • git log -1 для получения даты конфига    │
│  • определение списка устройств             │
├──────────┬──────────┬───────────────────────┤
│ Plugin:  │ Plugin:  │ Plugin:              │
│ D-Link   │ ELTEX    │ SNR                  │
│          │          │                      │
│ • Парсер │ • Парсер │ • Парсер             │
│ • Схема  │ • Схема  │ • Схема              │
│ • Поиск  │ • Поиск  │ • Поиск              │
└──────────┴──────────┴───────────────────────┘
```

## Установка

```bash
pip install -e .
```

## Запуск

```bash
python -m src.server
```

Для работы с Oxidized-репозиторием установите переменную окружения:

```
OXIDIZED_CONFIG_PATH=/srv/oxidized/configs
```

## Инструменты MCP

| Tool | Назначение |
|------|-----------|
| `list_devices` | Обзор парка устройств |
| `get_device_config` | Полный текст конфига + дата |
| `get_device_vlans` | VLAN (нормализованный вывод) |
| `get_device_acls` | Список ACL |
| `get_device_ntp` | Настройки NTP |
| `get_device_snmp` | Настройки SNMP |
| `get_device_interfaces` | Интерфейсы |
| `get_device_lldp` | LLDP конфигурация |
| `get_device_mac_table` | Статические MAC-записи |
| `get_device_voice_vlan` | Voice VLAN |
| `get_device_ssh` | SSH конфигурация |
| `search_across_devices` | Глобальный поиск по всем устройствам |
| `raw_search` | Сырой git grep |
